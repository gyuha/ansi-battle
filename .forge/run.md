## DoD 기준선 → 실행 후
1. HP(`#hp-txt`): 전술전 1400/1500/1400 → 300/300/300. 안시성 3000 → 3000(회귀 방지 검사라 변함없는 게 정상).
2. 게이지 비용(안시성 시작 50, `#mu-fill`): Space 50→50 → 50→40, Q 50→50 → 50→30, E 50→50 → 50→25, R 50→50 → 50→35.
3. 게이지 부족 차단(전술전 0번 시작, 게이지 0): `.cd` 오버레이 q/e/r/sp 0% → 100%. E 입력 후에도 100%. 추가로 확인한 것: E/Q/R/Space를 눌러도 게이지 0%, 기력 100%가 유지되어 비용이 전혀 빠지지 않았다.
4. 무쌍 대미지(grep): `30`/`100` 하드코딩 → `full ? 30 : 10` / `full ? 100 : 33`. 실제 동작은 UAT로 확인한다.
5. 문서(finder 재실행): index.html 120·121·122·124행, README 44·45·46·48·120행 반영. 페이지 실행 중 스크립트 오류 0건.

- 계획과의 차이는 거의 없다. 작업이 작아서 서브에이전트 워크플로 없이 메인 세션에서 직접 실행했다.
