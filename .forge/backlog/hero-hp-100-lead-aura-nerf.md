# 주장 너프 2차: 전술전 HP 100, 지휘 범위·사기 효과 완화

## 목표 / 비목표
- 목표: 주장 하나가 전황을 좌우하는 정도를 줄인다. 전술전 주장 HP를 300에서 100으로 낮추고, 주장 근처라는 이유만으로 생기는 이득(지휘 범위 패널티 차이, 아군 사기 오라, 적 사기 압박, 지휘 범위 반경)을 모든 전투에서 완화한다.
- 비목표:
  - 안시성 HP 3000은 유지한다.
  - 함성(R)의 효과(공격력 ×1.3·12초, 사기 회복, 재집결)는 바꾸지 않는다.
  - 무쌍·기술 게이지 비용·적장 수치는 바꾸지 않는다(#1에서 정한 값 유지).
  - 봇 재검증, 테스트 하네스 도입은 하지 않는다.

## 기준 출처
- 용어집: .forge/CONTEXT.md의 주장, 적장, 지휘 범위, 전술전, 무쌍전
- 관련 ADR: 없음
- 선행 조건: 작업 #1(`hero-nerf-musou-gauge-cost`)의 커밋되지 않은 변경(전술전 HP 300, README 120행 문장)이 작업 트리에 있는 상태를 기준으로 한다. #1이 되돌려졌다면 기준선이 달라지니 fg-run 시작 때 DoD 기준선으로 확인한다.
- 합의 수치:
  - 주장 HP: 전술전 세 전투(`js/data.js`의 `heroHp: 300` 세 곳) → **100**. 안시성 3000은 유지한다.
  - 지휘 범위 반경 `LEAD_R`: 320 → **250** (점선 원도 같은 상수를 쓰므로 자동으로 따라간다).
  - 범위 밖 부대: 공격력 ×0.7 → **×0.85**(근접 `js/game.js:475`, 원거리 `:491`), 받는 피해 ×1.25 → **×1.1**(`:510`), 사기 −1.2/초 → **−0.6/초**(`:368`).
  - 아군 사기 오라(반경 260): +1/초 → **+0.5/초**(`:374`).
  - 적 사기 압박(반경 180): −1/초 → **−0.5/초**(`:373`).
  - 적용 범위: 위 지휘·사기 수치는 전 전투 공통(상수만 바꾸며 모드 분기 없음).
- 완료 정의(DoD):
  1. **HP — 브라우저 실측.** `index.html`을 열고 전술전 0/1/2번과 안시성을 차례로 시작한 뒤 `#hp-txt`를 읽는다. 전술전은 `100 / 100`, 안시성은 `3000 / 3000`이어야 한다. (작성 시점: 전술전 `300 / 300`(#1 작업 트리 기준) — 정방향 검사로 현재 실패한다. 안시성 `3000 / 3000` — 회귀 방지 검사라 지금 통과하는 게 정상이다.)
  2. **지휘·사기 수치 — 코드 확인.** finder: `grep -n "LEAD_R = \|led ? 1 : \|!t.reg.led\|!r.led) r.morale\|hd < 180\|hd < 260" js/game.js`. 결과가 `LEAD_R = 250`, `led ? 1 : 0.85`(2곳), `m *= 1.1`, `morale -= 0.6 * dt`, `hd < 180` 줄의 `0.5 * dt`, `hd < 260` 줄의 `0.5 * dt`여야 한다. (작성 시점: 320 / 0.7 ×2 / 1.25 / 1.2 / 1 / 암묵적 1 — 현재 실패한다.) 문자열 검사인 이유: `js/game.js`가 IIFE로 감싸여 있어 밖에서 내부 상수와 부대 사기에 접근할 수 없다. 실제 체감은 4번 UAT로 확인한다.
  3. **문서.** finder: `git grep -n -E "320|30% 줄|25% 늘|HP\(300\)" -- README.md index.html`. README 75행은 250 / 15% 줄고 / 10% 늘며로 바꾸고, README 120행의 `HP(300)`은 `HP(100)`으로 바꾸면서 지휘 범위·사기 효과 완화도 "봇 재검증 안 함" 목록에 넣는다. README 72행의 "30% 줄어든다"(고수·언덕)는 이번 작업과 무관하니 그대로 둔다. `index.html` 129행 도움말에는 수치가 없으므로 수정하지 않는다.
  4. **UAT(사용자 직접 플레이).** 전술전에서 주장이 적진에 들어가면 금방 쓰러지는지, 주장이 다가가기만 해도 전황이 크게 뒤집히던 현상이 줄었는지, 주장을 가만히 두고 부대만 운용해도 쉽게 이기는 상태로 되돌아가지 않았는지 확인한다.
