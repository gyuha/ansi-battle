# 주장 너프: 전술전 HP 300·무쌍 대미지 1/3, 기술에 무쌍 게이지 소모

## 목표 / 비목표
- 목표: 전술전에서 주장 혼자 적진에 뛰어들어 전투를 이기지 못하게 한다. 전술전 주장 HP를 300으로, 전술전 무쌍 대미지를 1/3로 낮춘다. 모든 전투에서 돌진참·진각·함성·회피가 무쌍 게이지를 소모하게 한다.
- 비목표:
  - 안시성(무쌍전) HP 3000과 무쌍 대미지는 그대로 둔다.
  - 기존 쿨다운(Q 5초 / E 8초 / R 22초)과 기력 비용(Q 15 / 회피 22)은 바꾸지 않는다. 게이지 비용은 여기에 **더한다**.
  - 무쌍의 범위·지속시간·명중 인원 상한(cap)·넉백은 바꾸지 않는다. 바꾸는 것은 대미지뿐이다.
  - 무쌍 게이지 수급량(타격 +0.3, 처치 +0.8, 피격 2%)은 바꾸지 않는다.
  - 봇 재검증, 테스트 하네스 도입은 하지 않는다.

## 기준 출처
- 용어집: .forge/CONTEXT.md의 전술전, 무쌍전, 주장, 무쌍 게이지, 기력, 돌진참, 진각, 함성, 회피, 무쌍
- 관련 ADR: 없음
- 합의 수치:
  - 주장 HP: 살수·2번·3번 전투(`js/data.js`의 `mode: 'tactical'` 세 전투) 1400/1500/1400 → **300/300/300**. 안시성 3000은 유지한다.
  - 무쌍 대미지(전술전만): 연타 30 → **10**, 마지막 일격 100 → **33**. 분기는 기존 관례대로 `G.b.mode === 'musou'`로 한다.
  - 게이지 비용(전 전투): 회피 **10**, 함성 **15**, 돌진참 **20**, 진각 **25**. 게이지가 비용보다 모자라면 기술이 나가지 않는다(쿨다운·기력도 소모하지 않음). 무쌍 사용 조건(100)은 그대로 둔다.
  - UI: 게이지가 비용보다 모자라면 해당 기술 아이콘의 `.cd` 오버레이를 100%로 가린다. 회피 아이콘이 기력 부족일 때 가려지는 기존 방식과 같다. 쿨다운 표시는 유지한다.
- 완료 정의(DoD):
  1. **HP — 브라우저 실측.** `index.html`을 열고 각 전투를 시작한 뒤 `#hp-txt`를 읽는다. 전술전 0/1/2번은 `300 / 300`, 안시성은 `3000 / 3000`이어야 한다. (작성 시점: `1400 / 1400`, `1500 / 1500`, `1400 / 1400`, `3000 / 3000` — 전술전 세 항목은 정방향 검사로 현재 실패하고, 안시성 항목은 회귀 방지 검사라 지금 통과하는 게 정상이다.)
  2. **게이지 비용 — 브라우저 실측.** 안시성(시작 게이지 50)을 매번 새로 시작하고 키 하나를 누른 뒤 `#mu-fill` 폭을 읽는다. Space → 40, KeyQ → 30, KeyE → 25, KeyR → 35여야 한다(±2 허용). (작성 시점: 네 키 모두 50 → 50으로, 현재 실패한다.)
  3. **게이지 부족 시 차단 — 브라우저 실측.** 전술전 0번(시작 게이지 0)을 시작한 직후 `#sk-q .cd`, `#sk-e .cd`, `#sk-r .cd`, `#sk-sp .cd`의 `style.height`가 모두 `100%`여야 한다. 그 상태에서 KeyE를 누른 뒤 0.3초가 지나도 `#sk-e .cd`는 `100%`여야 한다. (작성 시점: 쿨다운 0, 기력 100이라 모두 `0%`로, 현재 실패한다.)
  4. **무쌍 대미지 — 코드 확인 + UAT.** `grep -n "heroArc(150\|heroArc(230" js/game.js` 결과에서 두 호출의 대미지 인자가 `G.b.mode === 'musou'` 분기를 거쳐 전술전 10/33, 무쌍전 30/100이 되어야 한다. 이 항목만 문자열 검사인 이유: `js/game.js` 전체가 IIFE로 감싸여 있어 내부 함수에 페이지 밖에서 접근할 수 없고, 피해 숫자는 캔버스에 그려져 DOM에서 읽을 수 없다. 그래서 실제 동작은 아래 6번 UAT에서 눈으로 확인한다.
  5. **문서.** 사이트 목록을 만든 명령: `git grep -n -E "돌진참|진각:|진각\.|함성[.:]|회피|무쌍 \(게이지|무쌍\. " -- index.html README.md`. 도움말 `index.html` 120·121·122·124행과 README 44·45·46·48행에 각 기술의 게이지 비용이 들어가야 한다. README 120행 난이도 문단에는 "이번 HP·무쌍·게이지 수치는 봇으로 다시 검증하지 않았다"는 문장이 들어가야 한다. (`index.html` 65·69행은 아이콘 라벨이라 수정 대상이 아니다.)
  6. **UAT(사용자 직접 플레이).** 전술전에서 주장이 적진 한가운데 들어가면 몇 초 안에 쓰러지고, 전술전 무쌍의 피해 숫자가 10/33 수준으로 보이며, 게이지가 모자랄 때 기술이 나가지 않아야 한다. 안시성은 HP 3000에 무쌍 피해 숫자가 30/100 수준이어야 한다.
  - 브라우저 실측(1~3)은 agent-browser로 `file://…/index.html`을 열고 eval로 실행한다. 전투 시작: `.tabs button[data-mode=…]` 클릭 → `#bitems .bi`[n] 클릭 → `#btn-start` 클릭 → 400ms 대기. 키 입력: `dispatchEvent(new KeyboardEvent('keydown'/'keyup', {code}))` → 150ms 대기 후 HUD를 읽는다.

- [ ] S2. `js/game.js` `updHero`의 무쌍 연타·마지막 일격 대미지를 `G.b.mode === 'musou'`가 아니면 10/33으로 바꾼다 — 완료 기준: DoD 4의 grep 결과가 기준과 일치
